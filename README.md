# Своя игра · Брейн-ринг · Хамса по Wi-Fi и через интернет

Программа для проведения интеллектуальных игр: **одно устройство — ведущий**, а **телефоны игроков становятся кнопками**.
Игрокам ничего не нужно устанавливать — достаточно браузера. Программа определяет, кто нажал кнопку первым
(с поправкой на задержку связи каждого телефона), ведёт счёт и время, показывает табло на экране/проекторе и повторяет
правила «Своей игры», «Брейн-ринга» и «Хамсы».

**Вопросы ведущий читает со своего листа** — из Word-документа, распечатки или планшета. Загружать их в программу
не нужно: она ведёт ход игры (раунды, темы, цены, очередь нажатий, таймеры и счёт), а содержание вопросов остаётся у ведущего.

Два способа играть:

- **В одной Wi-Fi сети** (по умолчанию): программа запускается на компьютере ведущего, телефоны подключаются к нему.
  Интернет во время игры не нужен.
- **Комнаты по коду — в локальной сети или через интернет** (`--rooms`): программа работает на сервере
  (или на вашем компьютере с туннелем), любой может создать комнату и стать её ведущим, а игроки входят
  по 6-значному коду — хоть из соседней комнаты, хоть из другого города. См. [«Игра через интернет»](#игра-через-интернет-и-комнаты-по-коду).

Стек: **Node.js** (Express + WebSocket) и **Vue 3** в браузерах.

## Возможности

- **Телефон = кнопка.** Игрок сканирует QR-код, вводит имя — и может играть. Экран телефона не гаснет, связь восстанавливается сама.
- **Честное определение первого.** Часы телефонов синхронизируются с компьютером, момент нажатия пересчитывается
  с учётом задержки сети, поэтому телефон со слабым Wi-Fi не проигрывает «быстрому». Ведущий видит очередь нажатий
  с отставанием в миллисекундах и временем реакции.
- **«Своя игра» по спортивным правилам** (как в «Эрудит-квартете»): темы по 5 вопросов стоимостью 10, 20, 30, 40, 50,
  за неверный ответ очки снимаются. Раунды **открытый, полуоткрытый, закрытый и командирский**: от команды тему играет
  один игрок, его выбирает капитан со своего телефона, нажимать кнопку может только он.
  Есть и **правила телепередачи**: табло, кот в мешке, аукцион, вопрос без риска, финал со ставками.
- **«Брейн-ринг» турниром**: бои команд по 5 вопросов, сигнал «Время!», минута на обсуждение, фальстарты, после ошибки
  соперникам — оставшееся время (не меньше 20 с). За победу в бою **+1 в турнирную таблицу** со **сквозным счётом**,
  ничья решается дополнительным вопросом.
- **«Хамса»**: пять раундов по пять тем — явный, полуявный, тайный, четвёртый (команды по очереди вычёркивают темы)
  и раунд «Хамса» со ставками. Стоимость вопросов растёт от 100–500 до 400–2000, нажатие до конца вопроса — фальстарт,
  после ошибки право ответа переходит к следующему нажавшему.
- **Командная игра** во всех режимах: в команде может быть несколько телефонов, нажатие любого — за команду.
- **Экран для зрителей** (проектор, телевизор, второй монитор): QR-код для подключения, табло с темами и ценами,
  номер вопроса, кто отвечает, таймеры, счёт.
- **Ход игры задаёте вы**: число раундов, тем и вопросов — прямо в лобби, названия тем ведущий вписывает щелчком
  по теме (их увидят экран и телефоны), спецвопросы отмечает кнопкой, когда дойдёт до них в своём листе.
- **Счёт**: «Верно» и «Неверно» сами прибавляют или отнимают цену вопроса, а **вручную** его можно поправить в любой
  момент — кнопки **− / +** у игрока или щелчок по счёту, чтобы вписать число.
- **Отмена любого действия ведущего** (Ctrl+Z), журнал событий, горячие клавиши.
- **Автосохранение**: если закрыть сервер или перезагрузить компьютер, игра продолжится с того же места, а телефоны переподключатся сами.
- Светлый современный интерфейс: крупное табло для проектора, большая кнопка на телефоне. Шрифт встроен в программу —
  интернет для этого не нужен.
- Звуковые сигналы (синтезируются, без файлов), вибрация на телефонах.
- **Пульт ведущего на телефоне**: панель ведущего подстраивается под экран телефона — большие кнопки «Верно» и «Неверно»
  рядом, таймер всегда на виду, список игроков со счётом на отдельной вкладке. Управлять игрой можно с телефона,
  планшета или ноутбука по ключу ведущего, а подключённый телефон игрока одним нажатием становится
  **вторым пультом ведущего** или **экраном для зрителей**.
- **Комнаты и игра через интернет**: создание комнаты в один клик, вход по коду, синхронный старт кнопок у игроков
  в разных местах, закрытие входа для новых игроков.

## Что понадобится

- Компьютер с Windows, macOS или Linux и **[Node.js](https://nodejs.org) версии 22 LTS** (подойдёт 20.19+).
- Wi-Fi роутер. Если роутера нет — включите на компьютере «Мобильный хот-спот» и подключите телефоны к нему.
- Телефоны с любым современным браузером (Chrome, Safari, Firefox, Яндекс Браузер).
- По желанию — проектор или телевизор, подключённый к компьютеру вторым экраном.

## Установка и запуск

1. Установите Node.js (LTS) с сайта [nodejs.org](https://nodejs.org).
2. Скачайте проект:
   ```sh
   git clone -b claude/multiplayer-quiz-game-lyfalp https://github.com/Niksimas/nhcg.git quiz
   cd quiz
   ```
   (или скачайте zip-архив ветки на GitHub и распакуйте).
3. Запустите:
   - **Windows** — двойной щелчок по `start.bat`;
   - **macOS** — двойной щелчок по `start.command`;
   - **Linux** — `./start.sh`;
   - или вручную: `npm install`, затем `npm start`.

   При первом запуске устанавливаются зависимости и собирается интерфейс (нужен интернет, 1–2 минуты).
   Дальше программа работает без интернета.
4. Автоматически откроется **панель ведущего** — `http://localhost:3000/host`. В окне сервера написаны адреса:

   ```
   Панель ведущего (на этом компьютере):  http://localhost:3000/host
   Экран для зрителей / проектора:        http://localhost:3000/screen
   Игрокам — открыть на телефоне в той же Wi-Fi сети:
       http://192.168.1.5:3000/
   ```

> **Windows:** при первом запуске появится окно брандмауэра — разрешите Node.js доступ к **частным сетям**.
> Если телефоны не подключаются, смотрите раздел [«Телефоны не подключаются»](#телефоны-не-подключаются).

## Как провести игру

### 1. Подготовка (лобби)

- Покажите игрокам **QR-код** (он есть в панели ведущего и на экране для зрителей). Игроки открывают ссылку,
  вводят имя и попадают в игру. Нажатие кнопки в лобби — проверка связи: имя игрока мигнёт у ведущего и на экране.
- Кнопка **«Экран»** открывает окно для зрителей — перетащите его на проектор и нажмите `F` (полный экран).
  Щёлкните по окну один раз, чтобы браузер разрешил звук.
- Выберите **режим** (Своя игра / Брейн-ринг / Хамса), при необходимости включите **командную игру** и создайте команды
  (игроки тоже могут создавать команды сами).
- В блоке **«Ход игры»** задайте правила, число раундов, тем в раунде и вопросов в теме (в брейн-ринге — вопросов в бою;
  у «Хамсы» всё задано правилами) и нажмите **«Начать игру»**.

### Вопросы — с вашего листа

Программа не хранит вопросов: по настройкам она строит «скелет» игры — раунды, темы по порядку, цены — и ведёт по нему
кнопки, время и счёт. Ведущий читает вопросы из своего документа.

- **Названия тем.** Щёлкните по теме на табло (в спортивной игре — ещё и по названию в таблице капитанов или в карточке
  темы) и впишите название из листа. Его увидят экран и телефоны. Пока название не вписано — «Тема 1», «Тема 2»…
- **Номер вопроса.** У ведущего и на экране видно, какой по счёту вопрос темы играется и сколько он стоит, — удобно
  сверяться с листом. Пока вы читаете, на экране и телефонах — «Слушайте вопрос»; когда откроете кнопки,
  телефоны загораются «Жми!».
- **Счёт** считается сам: «Верно» — плюс цена вопроса, «Неверно» — минус (штраф настраивается). Поправить вручную
  можно всегда: кнопки **− / +** у игрока в списке слева (шаг — цена текущего вопроса, в брейн-ринге — 1 очко)
  или щелчок по счёту, чтобы вписать число. `Ctrl+Z` отменяет последнее действие.
- **Спецвопросы** «Своей игры» (кот в мешке, аукцион, вопрос без риска) программа заранее не знает: если в вашем
  листе вопрос помечен как спецвопрос, нажмите нужную кнопку, пока его читаете.
- Число раундов, тем и вопросов можно поменять и во время игры (в настройках) — сыгранные вопросы останутся сыгранными.

### 2. «Своя игра» — спортивные правила (по умолчанию)

Правила взяты из «Эрудит-квартета» — командного варианта спортивной «Своей игры» (ссылки — в конце раздела).

- Раунд состоит из тем по **5 вопросов стоимостью 10, 20, 30, 40, 50**. Вопросы темы играются **подряд**.
- Ведущий читает вопрос и открывает кнопки (`Пробел`). Первый нажавший отвечает: верно — **плюс** стоимость вопроса,
  неверно — **минус** стоимость, и кнопки снова открываются для остальных. Раннее нажатие блокирует кнопку на секунду.
- В командной игре от каждой команды тему играет **один игрок** («за столом»). Нажимать кнопку может только он,
  очки идут команде. Кто играет, решает **капитан** (первый вошедший в команду; ведущий может назначить другого):
  - **открытый раунд** — все темы раунда объявлены заранее, капитаны сразу расставляют игроков по темам (1 минута);
  - **полуоткрытый** — тема объявляется перед игрой, капитан за 20 секунд выбирает, кто её играет;
  - **закрытый** — капитаны заранее ставят игроков на темы, не зная названий; тема открывается, когда игроки уже за столом;
  - **командирский** — все темы раунда играют капитаны.
- Капитаны выбирают игроков на своих телефонах и нажимают «Готово». Кого не выбрали — программа назначит сама
  (сначала тех, кто ещё не играл в этом раунде). Каждый игрок играет не больше одной темы за раунд, если игроков хватает.
- Раунды идут в порядке: открытый → полуоткрытый → закрытый → командирский. Вид любого раунда ведущий может
  поменять кнопками над темами. `Enter` ведёт игру дальше: выбор игроков → тема → вопросы по порядку → следующая тема.
- По умолчанию — 4 раунда по 4 темы из 5 вопросов; число раундов, тем и вопросов меняется в лобби.
- В настройках: стоимость вопросов (10–50, 1–5 или 100–500), играет ли тему один игрок или вся команда,
  время капитанам, штраф за ошибку, разрешить спецвопросы.

### 2а. «Своя игра» — правила телепередачи

Включаются в настройках («Правила → Как в телепередаче»).

1. Выбирающий игрок называет тему и цену — ведущий щёлкает по ячейке табло (или игрок выбирает вопрос прямо на своём телефоне).
2. Ведущий читает вопрос и нажимает **«Принимать ответы»** (`Пробел`). Кто нажал раньше разрешения — получает блокировку на 1 секунду.
3. Первый нажавший отвечает: **«Верно»** (`Enter`) — плюс цена вопроса, он выбирает следующий вопрос;
   **«Неверно»** (`Backspace`) — минус цена, кнопки снова открываются для остальных.
4. `Esc` — никто не знает, вопрос закрывается. `Enter` — вернуться к табло.
5. Спецвопрос из листа ведущий отмечает кнопкой, пока читает вопрос. **Кот в мешке** — выбравший отдаёт вопрос другому
   игроку (ведущий отмечает, кому, и стоимость). **Аукцион** — ведущий отмечает победителя торгов и ставку.
   **Вопрос без риска** — отвечает выбравший, цена удваивается, ошибка без штрафа.
6. Цены: 100–500 в первом раунде, 200–1000 во втором и так далее.
7. **Финал** (его можно выключить): игроки с положительным счётом делают ставки на телефонах, ведущий читает вопрос
   и открывает приём ответов — игроки пишут ответ, пока идёт время. Ведущий по очереди открывает ответы на экране
   и отмечает правильность. Затем — итоги с пьедесталом.

### 3. «Брейн-ринг» — турнир из боёв

1. Игра делится на **бои по 5 вопросов**. Перед боем ведущий отмечает, какие команды играют (обычно две;
   программа предлагает пару, которая ещё не встречалась). Кнопки работают только у команд этого боя.
2. `Enter` — следующий вопрос. Ведущий читает со своего листа вопрос с номером, который видит на экране.
3. `Пробел` — **«Время!»**: звучит сигнал, идёт минута. Нажатие до сигнала — **фальстарт**, команда не отвечает на этот вопрос.
4. Первая нажавшая команда отвечает, таймер на паузе. `Enter` — верно (+1 команде в этом бою), `Backspace` — неверно
   (соперники получают оставшееся время, но не меньше 20 секунд). Время вышло или все ошиблись — вопрос не взят.
5. После 5-го вопроса бой заканчивается сам: победитель получает **+1 в турнирную таблицу**. При равном счёте —
   **дополнительный вопрос** до первого верного ответа (можно выбрать «ничья» или «решает ведущий»).
6. **Сквозной счёт** турнира: взятые во всех боях вопросы плюс очки за победы. Таблица (бои, победы, ничьи,
   поражения, взятые вопросы, очки) видна ведущему и на экране между боями. «Итоги турнира» показывают победителя.
7. В настройках: число вопросов в бою, бой до N очков, очки за победу и ничью, как решать ничью, считать ли в
   турнирный счёт взятые вопросы или только победы, перенос очков невзятого вопроса, время.

### 4. «Хамса»

Командная игра, которую придумал азербайджанский знаток Фаик Гусейнов в 2006 году на основе «Эрудит-квартета».
«Хамса» по-арабски — «пять»: в команде 5 игроков, в игре 5 раундов, в раунде 5 тем по 5 вопросов.

| Раунд | Кто играет тему | Стоимость |
|---|---|---|
| 1. **Явный** | темы объявлены заранее, капитан за минуту расставляет игроков по темам | 100–500 |
| 2. **Полуявный** | тема объявляется перед игрой, капитан за 20 секунд выбирает игрока | 200–1000 |
| 3. **Тайный** | капитан заранее ставит игроков на темы, не зная их названий | 300–1500 |
| 4. **Четвёртый** | капитан выбирает одного игрока на весь раунд; команды по очереди — от меньшего счёта к большему — убирают темы, оставшуюся тему играют выбранные игроки | 400–2000 |
| 5. **«Хамса»** | один сложный вопрос для всей команды: играют команды с положительным счётом, ставка — от 1 до всех набранных очков, минута на обсуждение и 10 секунд на ответ | ставка |

- Как в спортивной «Своей игре», тему от команды играет один игрок, нажимать кнопку может только он.
  Капитаны выбирают игроков на своих телефонах, в четвёртом раунде капитан (или выбранный игрок) там же убирает темы.
- Нажатие кнопки **до конца чтения вопроса — фальстарт**: игрок теряет право ответа на этот вопрос.
- На ответ после нажатия — **3 секунды**. Верно — плюс стоимость, неверно — минус.
- После неверного ответа кнопки заново не открываются: **право ответа переходит к следующему**, кто успел нажать,
  и у него 5 секунд. Если больше никто не нажимал — кнопки открываются снова.
- Раунд «Хамса» играется как финал «Своей игры»: ставки и ответы команды пишут на телефонах, ведущий открывает
  ответы по очереди.
- Названия тем ведущий вписывает по ходу игры щелчком по теме, в четвёртом раунде — пока капитаны выбирают игрока.
  Стоимость вопросов программа считает сама (100 × номер вопроса × номер раунда).
- В настройках: стоимость вопроса в первом раунде, время на нажатие, на ответ и следующему игроку, время капитанам,
  время в раунде «Хамса», переход права ответа и штраф за ошибку. Вид любого раунда ведущий может поменять.

### Горячие клавиши ведущего

| Клавиша | «Своя игра» и «Хамса» | «Брейн-ринг» |
|---|---|---|
| `Пробел` | принимать ответы | «Время!» |
| `Enter` | верно / дальше (следующий вопрос, тема, раунд) | верно / следующий вопрос боя |
| `Backspace` | неверно | неверно |
| `Esc` | никто не знает — закрыть вопрос | — |
| `P` | пауза / продолжение таймера | пауза / продолжение таймера |
| `Ctrl+Z` | отменить последнее действие | отменить последнее действие |

На экране для зрителей: `F` — полный экран, `Q` — показать QR-код во время игры.

### Настройки

В панели ведущего (шестерёнка) настраиваются: правила «Своей игры» (спортивные или телевизионные), число раундов,
тем и вопросов, финал, стоимость вопросов, кто играет тему от команды, время капитанам, время на нажатие и на ответ,
штраф за неверный ответ, блокировка за раннее нажатие, спецвопросы, время в финале, правила «Хамсы» (стоимость, время,
переход права ответа), время вопроса в брейн-ринге и после ошибки, число вопросов в бою, очки за победу
и ничью, как решать ничью, сквозной счёт турнира, бой до N очков, перенос очков, выбор вопроса с телефона, режим
«Игроки в разных местах» (для игры через интернет), закрытие входа для новых игроков и другое.
Там же — «Новая игра» и полный сброс.

Сохранения игр и ключ ведущего хранятся в папке `data/` рядом с программой.

### Управление с другого устройства

Нажмите на QR-код в верхней панели ведущего → «Управлять игрой с другого устройства». Откройте эту ссылку на телефоне
или планшете — он станет вторым пультом ведущего. Ссылка содержит **ключ ведущего** — не показывайте её игрокам.
Без ключа панель ведущего с чужого устройства не откроется.

**Пульт на телефоне.** На узком экране панель ведущего перестраивается:

- сверху — режим игры, отмена, звук, настройки и QR-код (в режиме комнат — код комнаты);
- под шапкой, пока открыты кнопки или идёт ответ, — полоска с состоянием и таймером (пауза и +5 секунд там же);
- снизу — вкладки **«Игра»** (табло, вопрос, кнопки «Верно» и «Неверно» рядом, под большой палец) и **«Игроки»**
  (счёт с кнопками − / +, команды, журнал). Если, пока вы на вкладке «Игроки», кто-то нажал кнопку или выбрал вопрос,
  на вкладке «Игра» загорается красная точка;
- настройки и окно подключения выезжают снизу.

Если нужное устройство уже подключилось как игрок (например, телевизор или планшет помощника), в списке игроков
нажмите «сделать экраном» или «сделать ведущим» — устройство само переключится, игрок будет убран из игры.

### Откуда правила

Правила собраны по описаниям турниров по интеллектуальным играм:

- «Эрудит-квартет» (командная «Своя игра»: бои открытый, полуоткрытый, закрытый; темы по 5 вопросов 10–50; минус за
  ошибку): [правила ЛУК](http://luk.org.ua/documents/rules-ek), [статья на ЧГК-вики](https://chgk.fandom.com/wiki/Эрудит-Квартет),
  [регламент турнира МАК ЧГК](http://mak-chgk.ru/post_16811/);
- командная «Своя игра»: [правила командной «Своей игры»](https://pecheny.me/blog/rules-teamsi/);
- «Брейн-ринг» (бои по 5 вопросов, фальстарт, минута и 20 секунд после ошибки, очки за победу в бою, таблица):
  [правила ЛУК](http://luk.org.ua/documents/rules-br), [правила Кубка Европы](http://windflower.spb.ru/ke/common/reglaments/brainlaws.html),
  [Википедия](https://ru.wikipedia.org/wiki/Брейн-ринг);
- «Хамса» (пять раундов, стоимость по раундам, фальстарт, 3 секунды на ответ, переход права ответа, вычёркивание тем,
  ставки): [правила «Хамсы»](https://cnacu.livejournal.com/83655.html), [Циклопедия](https://cyclowiki.org/wiki/Хамса_(игра)),
  [правила клуба КИТ](http://kit-saransk.ru/news/2014-2015/pravila-igryi-xamsa.html),
  [регламент турнира](https://znatokiada.livejournal.com/183180.html), [описание на iqga.me](https://iqga.me/games/khamsa/).

«Командирского» раунда в этих правилах нет — он сделан по вашему описанию: темы играют капитаны команд.
Всё, что в разных турнирах отличается (очки за победу, ничья, число вопросов, время), вынесено в настройки.

## Игра через интернет и комнаты по коду

В режиме комнат сервер обслуживает сразу много игр. Любой открывает главную страницу сайта и:

- **«Создать комнату»** — становится ведущим новой игры и получает код комнаты (например, `482 915`);
- **вводит код** — и попадает в игру как игрок (или открывает её как экран для зрителей).

Всё остальное — как в игре по Wi-Fi: режимы, табло, отмена, настройки. Ключ ведущего комнаты хранится в
браузере создателя; чтобы вести игру с другого устройства, откройте ссылку из окна «Подключение игроков».

### Как вести игру, если игроки в разных местах

1. Создайте комнату и включите в окне «Подключение игроков» (или в настройках) **«Игроки в разных местах»**.
2. Созвонитесь в любом видеосервисе (Zoom, Telegram, Discord…) и читайте вопросы голосом. Табло и счёт можно
   показать через демонстрацию **экрана для зрителей** (кнопка «Экран» в панели ведущего).
3. Игроки открывают сайт на телефоне и вводят код.

Почему кнопки открываются «по сигналу на телефоне»: у каждого своя задержка видеосвязи (от 0,2 до 2 секунд), поэтому
открывать кнопки по голосу ведущего нечестно. Когда ведущий нажимает «Принимать ответы» или «Время!», сервер
назначает момент открытия чуть в будущем — так, чтобы команда успела дойти до всех телефонов, — и в этот момент
у всех одновременно загорается «Жми!». Нажатие до сигнала — «Рано!» в «Своей игре» и фальстарт в «Брейн-ринге».
Часы телефонов синхронизированы с сервером, поэтому игрок с медленным интернетом не проигрывает из-за задержки.

### Вариант 1. Свой компьютер + бесплатный туннель (без аренды сервера)

Подойдёт, чтобы сыграть с друзьями прямо сейчас. Компьютер должен быть включён всю игру.

1. Запустите программу в режиме комнат: `npm start -- --rooms` (или `start.bat --rooms` / `./start.sh --rooms`).
2. Установите [cloudflared](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/)
   и запустите в другом окне:
   ```sh
   cloudflared tunnel --url http://localhost:3000
   ```
   Он покажет адрес вида `https://какие-то-слова.trycloudflare.com`.
3. Откройте **этот адрес** в своём браузере и создайте комнату — ссылка и QR-код для игроков будут вести на него же.
   Отправьте игрокам адрес и код комнаты.

Подойдёт и ngrok (`ngrok http 3000`), но в бесплатной версии он показывает игрокам страницу-предупреждение.

### Вариант 2. Свой сервер (VPS) с доменом и HTTPS — Docker

Нужен VPS с Linux (1 ГБ памяти хватит на десятки комнат) и домен, указывающий на сервер.

```sh
git clone -b claude/multiplayer-quiz-game-lyfalp https://github.com/Niksimas/nhcg.git quiz && cd quiz
cp .env.example .env        # впишите свой домен: QUIZ_DOMAIN=quiz.example.ru
docker compose up -d        # приложение + Caddy с автоматическим сертификатом HTTPS
```

Игра откроется по адресу `https://quiz.example.ru`. Данные (комнаты и сохранения игр) лежат в томе `quiz-data`.
Обновление: `git pull && docker compose up -d --build`.

### Вариант 3. Свой сервер без Docker

```sh
npm ci && npm run build
node server/index.js --rooms --no-open --host 127.0.0.1 --port 3000 \
  --trust-proxy --public-url https://quiz.example.ru --data /var/lib/quiz
```

Перед ним нужен веб-сервер с HTTPS, пропускающий WebSocket: примеры для nginx и systemd — в папке [`deploy/`](deploy).
Можно и без прокси: `--tls-cert fullchain.pem --tls-key privkey.pem --port 443`.

### Комнаты в локальной сети

`npm start -- --rooms` работает и без интернета: например, в школе несколько классов играют каждый в своей комнате
на одном компьютере-сервере. Игроки открывают адрес компьютера (его показывает окно сервера) и вводят код.

### Лимиты и безопасность сервера комнат

| Параметр | По умолчанию | Как изменить |
| --- | --- | --- |
| Комнат одновременно | 500 | `--max-rooms` / `MAX_ROOMS` |
| Удаление комнаты без игры | через 12 часов | `--room-ttl` / `ROOM_TTL_HOURS` |
| Создание комнат с одного IP | 10 за 10 минут | `--room-create-limit` / `ROOM_CREATE_LIMIT` |

Ещё: перебор кодов комнат ограничен (30 неудачных попыток в минуту с одного IP), ключ ведущего не передаётся
на сторонние сайты. В режиме комнат панель ведущего всегда требует ключ — даже на самом сервере.

## Честная кнопка: как это работает

1. Каждый телефон несколько раз в секунду обменивается с компьютером метками времени (как NTP) и вычисляет,
   на сколько его часы отличаются от часов компьютера. Используются самые быстрые обмены — они точнее всего.
2. При нажатии телефон отправляет **момент касания экрана**, переведённый в часы компьютера.
3. Компьютер ждёт короткое «окно» (40–300 мс, по худшей задержке в зале) и выбирает самое раннее нажатие.
   Так телефон, чей сигнал идёт дольше, не проигрывает, если на самом деле нажал раньше.
4. Защита от подмены: сдвинуть нажатие «в прошлое» можно не больше, чем на измеренную сервером задержку этого телефона
   (максимум 300 мс, при игре через интернет — 1 с).

Ведущий видит у каждого игрока пинг, а после нажатий — очередь с отставанием в миллисекундах.

## Телефоны не подключаются

- Телефоны и компьютер должны быть в **одной** Wi-Fi сети. **Гостевые сети** роутеров обычно запрещают устройствам
  связываться друг с другом — используйте основную сеть.
- **Windows:** разрешите Node.js в брандмауэре: «Брандмауэр Защитника Windows» → «Разрешить взаимодействие
  с приложением» → отметьте Node.js для частных сетей. Проверьте, что Wi-Fi сеть помечена как **частная**, а не общественная.
- Адрес набирайте полностью, с `http://` и портом, например `http://192.168.1.5:3000` (не https).
- Если у компьютера несколько сетей (VPN, виртуальные машины), нажмите на QR-код в панели ведущего и выберите правильный адрес.
- Нет роутера — включите «Мобильный хот-спот» на компьютере (Windows: Параметры → Сеть → Мобильный хот-спот).
- Если связь «тормозит» — подойдите ближе к роутеру; пинг каждого игрока виден ведущему.

## Параметры запуска

```sh
npm start -- --port 8080        # другой порт (если занят — берётся следующий свободный)
npm start -- --no-open          # не открывать браузер
npm start -- --data D:\quiz     # где хранить сохранения игр
npm start -- --require-key      # спрашивать ключ ведущего даже на этом компьютере
npm start -- --rooms            # режим комнат (игра через интернет, много игр на одном сервере)
npm start -- --help             # все параметры, включая лимиты сервера комнат
```

Все параметры можно задать и переменными окружения (`PORT`, `DATA_DIR`, `ROOMS=1`, `PUBLIC_URL`, `TRUST_PROXY=1`…).
