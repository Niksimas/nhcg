# Своя игра · Брейн-ринг по Wi-Fi

Программа для проведения интеллектуальных игр: **один компьютер — ведущий**, а **телефоны игроков становятся кнопками**.
Все устройства подключаются к одной Wi-Fi сети, игрокам ничего не нужно устанавливать — достаточно браузера.
Компьютер определяет, кто нажал кнопку первым (с поправкой на задержку Wi-Fi каждого телефона), ведёт счёт,
показывает вопросы на экране/проекторе и повторяет правила «Своей игры» и «Брейн-ринга».

Стек: **Node.js** (Express + WebSocket) на компьютере ведущего и **Vue 3** в браузерах. Интернет во время игры не нужен.

## Возможности

- **Телефон = кнопка.** Игрок сканирует QR-код, вводит имя — и может играть. Экран телефона не гаснет, связь восстанавливается сама.
- **Честное определение первого.** Часы телефонов синхронизируются с компьютером, момент нажатия пересчитывается
  с учётом задержки сети, поэтому телефон со слабым Wi-Fi не проигрывает «быстрому». Ведущий видит очередь нажатий
  с отставанием в миллисекундах и временем реакции.
- **«Своя игра»**: табло тем и цен, несколько раундов, кот в мешке, аукцион, вопрос без риска, финал со ставками
  и письменными ответами с телефонов, выбор вопроса с телефона, штраф за неверный ответ, блокировка за раннее нажатие.
- **«Брейн-ринг»**: сигнал «Время!», минута на обсуждение, фальстарты, после ошибки соперникам — оставшееся время
  (не меньше 20 с), перенос очков невзятого вопроса, бой до заданного счёта. Можно играть **без пакета** — ведущий читает вопросы с листа.
- **Командная игра** в обоих режимах: в команде может быть несколько телефонов, нажатие любого — за команду.
- **Экран для зрителей** (проектор, телевизор, второй монитор): QR-код для подключения, табло, вопросы с картинками,
  звуком и видео, таймеры, счёт. Ответы на нём не видны, пока их не откроет ведущий.
- **Пакеты вопросов**: встроенные демо-пакеты, **импорт пакетов SIGame (.siq)**, свой формат JSON, **редактор пакетов**
  с загрузкой картинок, звука и видео, экспорт в .zip.
- **Отмена любого действия ведущего** (Ctrl+Z), ручная правка счёта, журнал событий, горячие клавиши.
- **Автосохранение**: если закрыть сервер или перезагрузить компьютер, игра продолжится с того же места, а телефоны переподключатся сами.
- Звуковые сигналы (синтезируются, без файлов), вибрация на телефонах.
- Управление игрой с планшета или ноутбука по ключу ведущего.

## Что понадобится

- Компьютер с Windows, macOS или Linux и **[Node.js](https://nodejs.org) версии 22 LTS** (подойдёт 20.19+).
- Wi-Fi роутер. Если роутера нет — включите на компьютере «Мобильный хот-спот» и подключите телефоны к нему.
- Телефоны с любым современным браузером (Chrome, Safari, Firefox, Яндекс Браузер).
- По желанию — проектор или телевизор, подключённый к компьютеру вторым экраном.

## Установка и запуск

1. Установите Node.js (LTS) с сайта [nodejs.org](https://nodejs.org).
2. Скачайте проект:
   ```sh
   git clone -b claude/multiplayer-quiz-game-lyfalp https://github.com/Niksimas/nhcg.git quiz
   cd quiz
   ```
   (или скачайте zip-архив ветки на GitHub и распакуйте).
3. Запустите:
   - **Windows** — двойной щелчок по `start.bat`;
   - **macOS** — двойной щелчок по `start.command`;
   - **Linux** — `./start.sh`;
   - или вручную: `npm install`, затем `npm start`.

   При первом запуске устанавливаются зависимости и собирается интерфейс (нужен интернет, 1–2 минуты).
   Дальше программа работает без интернета.
4. Автоматически откроется **панель ведущего** — `http://localhost:3000/host`. В окне сервера написаны адреса:

   ```
   Панель ведущего (на этом компьютере):  http://localhost:3000/host
   Экран для зрителей / проектора:        http://localhost:3000/screen
   Игрокам — открыть на телефоне в той же Wi-Fi сети:
       http://192.168.1.5:3000/
   ```

> **Windows:** при первом запуске появится окно брандмауэра — разрешите Node.js доступ к **частным сетям**.
> Если телефоны не подключаются, смотрите раздел [«Телефоны не подключаются»](#телефоны-не-подключаются).

## Как провести игру

### 1. Подготовка (лобби)

- Покажите игрокам **QR-код** (он есть в панели ведущего и на экране для зрителей). Игроки открывают ссылку,
  вводят имя и попадают в игру. Нажатие кнопки в лобби — проверка связи: имя игрока мигнёт у ведущего и на экране.
- Кнопка **«Экран»** открывает окно для зрителей — перетащите его на проектор и нажмите `F` (полный экран).
  Щёлкните по окну один раз, чтобы браузер разрешил звук.
- Выберите **режим** (Своя игра / Брейн-ринг), при необходимости включите **командную игру** и создайте команды
  (игроки тоже могут создавать команды сами).
- Выберите **пакет вопросов** (для «Своей игры» обязательно, для «Брейн-ринга» — по желанию) и нажмите **«Начать игру»**.

### 2. «Своя игра»

1. Выбирающий игрок называет тему и цену — ведущий щёлкает по ячейке табло (или игрок выбирает вопрос прямо на своём телефоне).
2. Ведущий читает вопрос и нажимает **«Принимать ответы»** (`Пробел`). Кто нажал раньше разрешения — получает блокировку на 1 секунду.
3. Первый нажавший отвечает: **«Верно»** (`Enter`) — плюс цена вопроса, он выбирает следующий вопрос;
   **«Неверно»** (`Backspace`) — минус цена, кнопки снова открываются для остальных.
4. `Esc` — никто не знает, показать ответ. `Enter` — вернуться к табло.
5. **Кот в мешке** — выбравший отдаёт вопрос другому игроку (ведущий отмечает, кому, и стоимость).
   **Аукцион** — ведущий отмечает победителя торгов и ставку. **Вопрос без риска** — отвечает выбравший, цена удваивается, ошибка без штрафа.
6. **Финал:** ведущий убирает темы, игроки с положительным счётом делают ставки на телефонах, затем пишут ответ.
   Ведущий по очереди открывает ответы на экране и отмечает правильность. Затем — итоги с пьедесталом.

### 3. «Брейн-ринг»

1. `Enter` — следующий вопрос. Ведущий читает вопрос (текст можно показать на экране галочкой).
2. `Пробел` — **«Время!»**: звучит сигнал, идёт минута. Нажатие до сигнала — **фальстарт**, команда не отвечает на этот вопрос.
3. Первая нажавшая команда отвечает, таймер на паузе. `Enter` — верно (очки команде), `Backspace` — неверно
   (соперники получают оставшееся время, но не меньше 20 секунд).
4. Если время вышло или все ошиблись — вопрос не взят, его очки переходят на следующий вопрос.
5. «Завершить бой» показывает победителя, «Новый бой» обнуляет счёт.

### Горячие клавиши ведущего

| Клавиша | «Своя игра» | «Брейн-ринг» |
|---|---|---|
| `Пробел` | принимать ответы | «Время!» |
| `Enter` | верно / к табло / следующий раунд | верно / следующий вопрос |
| `Backspace` | неверно | неверно |
| `Esc` | показать ответ | — |
| `P` | пауза / продолжение таймера | пауза / продолжение таймера |
| `Ctrl+Z` | отменить последнее действие | отменить последнее действие |

На экране для зрителей: `F` — полный экран, `Q` — показать QR-код во время игры.

### Настройки

В панели ведущего (шестерёнка) настраиваются: время на нажатие и на ответ, штраф за неверный ответ, блокировка
за раннее нажатие, время в финале, время вопроса в брейн-ринге и после ошибки, бой до N очков, перенос очков,
показ вопроса на телефонах, выбор вопроса с телефона, скрытие ответа на экране ведущего и другое.
Там же — «Новая игра» и полный сброс.

### Управление с другого устройства

Нажмите на QR-код в верхней панели ведущего → «Управлять игрой с другого устройства». Откройте эту ссылку на планшете —
он станет вторым пультом ведущего. Ссылка содержит **ключ ведущего** — не показывайте её игрокам.
Без ключа панель ведущего с чужого устройства не откроется.

## Пакеты вопросов

- **Встроенные:** «Демо: Своя игра» (2 раунда, спецвопросы, картинки, мелодии, финал) и «Демо: Брейн-ринг».
- **Пакеты SIGame (.siq)** — «Пакеты» → «Импорт файла». Поддерживаются старый и новый формат, картинки, звук и видео,
  кот в мешке, аукцион, вопрос без риска, финальный раунд.
- **Редактор:** «Пакеты» → «Создать пакет» (или «Копия для правки» у встроенного). Раунды, темы, цены,
  текст, картинки, звук, видео, ответ, комментарий для ведущего. Сохранение — `Ctrl+S`.
- **Экспорт** в .zip (со всеми файлами) — чтобы перенести пакет на другой компьютер и импортировать там.
- **Свой JSON** — можно написать вручную:

```json
{
  "title": "Мой пакет",
  "rounds": [
    {
      "name": "Раунд 1",
      "themes": [
        {
          "name": "География",
          "questions": [
            { "price": 100, "question": "Самый большой океан?", "answer": "Тихий" },
            { "price": 200, "question": "Чей это флаг?", "image": "https://example.com/flag.png", "answer": "Япония" },
            { "price": 300, "type": "cat", "catTheme": "Коты", "catPrice": 500, "question": "…", "answer": "…" }
          ]
        }
      ]
    },
    { "name": "Финал", "type": "final", "themes": [{ "name": "Космос", "questions": [{ "question": "…", "answer": "…" }] }] }
  ]
}
```

Типы вопросов: `normal`, `cat` (кот в мешке), `auction` (аукцион), `norisk` (без риска).
Для брейн-ринга достаточно списка: `{ "title": "…", "questions": [{ "question": "…", "answer": "…" }] }`.
Полное описание формата — в начале файла `server/packs/normalize.js`.

Пакеты, сохранения и ключ ведущего хранятся в папке `data/` рядом с программой.

## Честная кнопка: как это работает

1. Каждый телефон несколько раз в секунду обменивается с компьютером метками времени (как NTP) и вычисляет,
   на сколько его часы отличаются от часов компьютера. Используются самые быстрые обмены — они точнее всего.
2. При нажатии телефон отправляет **момент касания экрана**, переведённый в часы компьютера.
3. Компьютер ждёт короткое «окно» (40–300 мс, по худшей задержке в зале) и выбирает самое раннее нажатие.
   Так телефон, чей сигнал идёт дольше, не проигрывает, если на самом деле нажал раньше.
4. Защита от подмены: сдвинуть нажатие «в прошлое» можно не больше, чем на измеренную сервером задержку этого телефона
   (максимум 300 мс).

Ведущий видит у каждого игрока пинг, а после нажатий — очередь с отставанием в миллисекундах.

## Телефоны не подключаются

- Телефоны и компьютер должны быть в **одной** Wi-Fi сети. **Гостевые сети** роутеров обычно запрещают устройствам
  связываться друг с другом — используйте основную сеть.
- **Windows:** разрешите Node.js в брандмауэре: «Брандмауэр Защитника Windows» → «Разрешить взаимодействие
  с приложением» → отметьте Node.js для частных сетей. Проверьте, что Wi-Fi сеть помечена как **частная**, а не общественная.
- Адрес набирайте полностью, с `http://` и портом, например `http://192.168.1.5:3000` (не https).
- Если у компьютера несколько сетей (VPN, виртуальные машины), нажмите на QR-код в панели ведущего и выберите правильный адрес.
- Нет роутера — включите «Мобильный хот-спот» на компьютере (Windows: Параметры → Сеть → Мобильный хот-спот).
- Если связь «тормозит» — подойдите ближе к роутеру; пинг каждого игрока виден ведущему.

## Параметры запуска

```sh
npm start -- --port 8080        # другой порт (если занят — берётся следующий свободный)
npm start -- --no-open          # не открывать браузер
npm start -- --data D:\quiz     # где хранить пакеты и сохранения
npm start -- --require-key      # спрашивать ключ ведущего даже на этом компьютере
```

## Для разработчиков

```sh
npm install
npm run dev        # сервер + Vite с горячей перезагрузкой, всё на одном порту
npm test           # тесты сервера: движок, честная кнопка, пакеты, SIGame, WebSocket
npm run build      # проверка типов + сборка интерфейса в dist/
npm run test:e2e   # браузерные сценарии (нужен Playwright: npm i --no-save playwright && npx playwright install chromium)
```

Структура:

```
server/                 сервер (Node.js)
  index.js              запуск, адреса в сети, раздача интерфейса
  hub.js                WebSocket: ведущий, экраны, игроки, синхронизация часов
  http.js               API пакетов и медиафайлов
  game/                 игровая логика: game.js (игроки, кнопка, таймеры, отмена),
                        jeopardy.js («Своя игра»), brainring.js («Брейн-ринг»), buzzer.js (честная кнопка)
  packs/                хранение, проверка и импорт пакетов (JSON, zip, SIGame .siq)
  demo-packs/           встроенные пакеты
  test/                 тесты (node --test)
client/src/             интерфейс (Vue 3 + TypeScript)
  views/PlayerView.vue  телефон игрока
  views/HostView.vue    панель ведущего (+ views/host/*)
  views/ScreenView.vue  экран для зрителей (+ views/screen/*)
  views/EditorView.vue  редактор пакетов
  lib/connection.ts     WebSocket-клиент с переподключением и синхронизацией часов
tests/e2e/              браузерные сценарии (Playwright)
```
